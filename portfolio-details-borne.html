Une Borne de Commande de A à Z en C#

Application desktop développée en WPF (.NET / C#) simulant une borne de commande interactive pour restaurant, du choix du menu jusqu'à la validation du panier — avec un back-office d'administration complet.

Ce projet suit une architecture en couches rigoureuse (Modèles, Services, Vues) et couvre l'intégralité du cycle d'une commande côté client ainsi que la gestion opérationnelle côté employé/admin. La persistance est assurée de manière hybride : les plats et la configuration sont stockés en JSON local, tandis que l'authentification et l'historique des connexions reposent sur une base MySQL/MariaDB avec hachage BCrypt. La couleur d'accentuation de l'interface est configurable à chaud depuis le panneau admin, grâce à une ressource WPF dynamique (AccentBrush).

Fonctionnalités Principales

Borne Client Interactive

Écran d'accueil avec choix du mode ("Sur place" / "À emporter"), catalogue filtrable par catégorie et recherche texte, panier en temps réel avec ajout, incrément, décrément et suppression de lignes.

Administration Multi-onglets

Back-office à 4 onglets : gestion des plats (CRUD DataGrid), configuration de la borne, paramètres de connexion MySQL avec test asynchrone, et historique des 500 dernières connexions.

Thème Dynamique en Direct

La couleur d'accentuation est une ressource WPF dynamique (AccentBrush) modifiable à la volée depuis l'admin — palette de swatches ou saisie hexadécimale — avec aperçu instantané sans redémarrage.

Authentification & Sessions

Connexion admin sécurisée via BCrypt contre une base MySQL. Gestion de session statique avec rôles "admin" et "employé", accès à l'AdminWindow restreint aux administrateurs authentifiés.

Persistance Hybride

Plats et configuration stockés localement en JSON (AppData) via des singletons chargés une fois au démarrage. Les données métier évoluent indépendamment de la connexion à la base de données.

Défis Techniques Relevés

01
Mise à Jour du Panier sans INotifyPropertyChanged

LigneCommande n'implémentant pas INotifyPropertyChanged, chaque modification de quantité nécessite un reset manuel de l'ItemsSource du DataGrid panier pour forcer le rafraîchissement visuel — contournement technique documenté et maîtrisé.

02
Ressource WPF Dynamique pour le Thème

La couleur d'accentuation est injectée comme ressource dynamique globale (Application.Current.Resources["AccentBrush"]), permettant de repeindre l'ensemble de l'interface à chaud depuis le panneau admin sans rechargement de la fenêtre principale.

03
Cohérence des Données Admin / Client

Le PlatService étant un singleton chargé une fois au démarrage, CommandeView le recharge explicitement à chaque nouvelle commande afin de refléter immédiatement toute modification effectuée dans l'onglet Plats de l'admin, sans redémarrage de l'application.

04
Test de Connexion MySQL Asynchrone

La méthode statique AuthService.TestConnectionAsync permet de valider les paramètres de connexion à la base de données directement depuis l'onglet "Base de données" de l'admin — retour visuel immédiat, sans bloquer le thread UI grâce à l'usage de async/await.
