Notions de programmation

Typescript

est un langage superset de Javascript, offrant des fonctionnalités plus avancées, notamment la gestion des types.

React

permet de construire des interfaces utilisateurs à partir de briques individuelles appelées composants.

Postgresql

est un système de gestion de base de données relationnelle et objet. C'est un outil libre disponible mettant l’accent sur l’extensibilité et la conformité avec SQL.

PHP

est un langage de programmation libre, principalement utilisé pour produire des pages Web dynamiques via un serveur web[5], mais pouvant également fonctionner comme n'importe quel langage interprété de façon locale. PHP est un langage impératif orienté objet.

HTML5

est la dernière révision majeure du HTML (format de données conçu pour représenter les pages web) et le langage de feuille de style en cascade.

CSS

est un langage informatique qui décrit la présentation des documents HTML et XML. Les standards définissant CSS sont publiés par le World Wide Web Consortium (W3C).
