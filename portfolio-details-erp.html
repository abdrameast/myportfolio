C'est quoi un ERP ?

Un ERP (Enterprise Resource Planning) est un système d'information centralisé qui regroupe l'ensemble des processus opérationnels d'une entreprise sur une seule base de données.

Dans le secteur de la location de véhicules, ce logiciel élimine les fichiers Excel dispersés en regroupant la gestion de la flotte automobile, le suivi des clients et prospects, les contrats de location, la facturation et les statistiques au sein d'une même application web sécurisée, rapide et facile d'accès pour les employés de l'agence.

Fonctionnalités Principales

Module CRM — Prospects

Système complet de CRUD (Création, Lecture, Modification, Suppression) pour la base de prospects B2B et B2C de l'agence. Conversion prospect → client intégrée.

Recherche & Pagination

Barre de recherche instantanée pour retrouver tout contact, couplée à une pagination fluide pour naviguer dans de grandes bases de données clients.

Tableau de Bord

Calcul et affichage de statistiques globales en temps réel — nombre de prospects, conversions, clients actifs — pour piloter l'activité commerciale.

Notifications Flash

Système de messages flash via $_SESSION['message'] informant l'utilisateur du succès ou de l'échec de ses actions (création, mise à jour, format email invalide).

Module Flotte (à venir)

Architecture extensible pensée dès le départ pour intégrer la gestion de la flotte automobile, des contrats et de la facturation.

Extrait d'Architecture — Pattern DAO

Séparation stricte entre accès données et logique métier, garantissant maintenabilité et évolutivité.

ProspectDao.php
// DAO — Couche d'accès aux données (Data Access Object) class ProspectDao { private PDO $pdo; public function findAll(int $limit, int $offset): array { // Requête préparée → protection contre les injections SQL $stmt = $this->pdo->prepare( "SELECT * FROM prospects LIMIT :limit OFFSET :offset" ); $stmt->execute(['limit' => $limit, 'offset' => $offset]); return $stmt->fetchAll(PDO::FETCH_CLASS, Prospect::class); } public function save(Prospect $p): bool { // Validation email avant toute persistance $email = filter_var($p->getEmail(), FILTER_SANITIZE_EMAIL); if (!filter_var($email, FILTER_VALIDATE_EMAIL)) return false; // INSERT préparé... } }

Défis Techniques Relevés

01
Architecture Logicielle MVC Stricte

Mise en place d'une séparation nette entre requêtes en base de données (DAO), logique métier (Contrôleurs) et affichage HTML (Vues) — rendant le code maintenable et prêt à évoluer pour l'ajout du module Flotte de véhicules.

02
Fiabilité & Intégrité des Données

Implémentation d'une validation rigoureuse des saisies avec FILTER_SANITIZE_EMAIL et htmlspecialchars pour contrer les injections XSS et garantir l'intégrité des informations commerciales (nom, prénom, format d'email obligatoires).

03
Gestion d'État via Sessions PHP

Mise en œuvre d'un système de notifications flash basé sur $_SESSION['message'], offrant un feedback utilisateur immédiat sans rechargement de page supplémentaire.

04
Pagination & Performance des Requêtes

Conception d'un système de pagination dynamique côté serveur (LIMIT/OFFSET) maintenant des performances constantes quelle que soit la taille de la base de prospects.
