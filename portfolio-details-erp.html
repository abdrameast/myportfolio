C'est quoi un ERP ?

Un ERP (Enterprise Resource Planning) est un système d'information centralisé qui regroupe l'ensemble des processus opérationnels d'une entreprise sur une seule base de données.

Dans le secteur de la location de véhicules, ce logiciel élimine les fichiers Excel dispersés en regroupant la gestion de la flotte automobile, le suivi des clients et prospects, les contrats de location, la facturation et les statistiques au sein d'une même application web sécurisée, rapide et facile d'accès pour les employés de l'agence.

Pattern DAO — accès aux données

Séparation stricte entre accès aux données et logique métier, garantissant maintenabilité et évolutivité.

ProspectDao.php 
// DAO — Couche d'accès aux données (Data Access Object)
class ProspectDao {

  private PDO $pdo;

  public function findAll(int $limit, int $offset): array {
    // Requête préparée → protection contre les injections SQL
    $stmt = $this->pdo->prepare(
      "SELECT * FROM prospects LIMIT :limit OFFSET :offset"
    );
    $stmt->execute(['limit' => $limit, 'offset' => $offset]);
    return $stmt->fetchAll(PDO::FETCH_CLASS, Prospect::class);
  }

  public function save(Prospect $p): bool {
    // Validation email avant toute persistance
    $email = filter_var($p->getEmail(), FILTER_SANITIZE_EMAIL);
    if (!filter_var($email, FILTER_VALIDATE_EMAIL)) return false;
    // INSERT préparé...
  }
}
Ingénierie

Défis techniques relevés

01

Architecture logicielle MVC stricte

Séparation nette entre requêtes en base (DAO), logique métier (Contrôleurs) et affichage HTML (Vues) — un code maintenable, prêt à évoluer pour l'ajout du module Flotte.

02

Fiabilité & intégrité des données

Validation rigoureuse des saisies avec FILTER_SANITIZE_EMAIL et htmlspecialchars pour contrer les injections XSS et garantir l'intégrité des informations commerciales.

03

Gestion d'état via sessions PHP

Système de notifications flash basé sur $_SESSION['message'], offrant un feedback utilisateur immédiat sans rechargement de page supplémentaire.

04

Pagination & performance des requêtes

Pagination dynamique côté serveur (LIMIT / OFFSET) maintenant des performances constantes quelle que soit la taille de la base de prospects.
