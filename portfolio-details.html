ASKILLS

Plateforme harmonisant le suivi des compétences, projets et ressources humaines en environnement technique complexe

Transformation Digitale pour Assystem

Application moderne conçue pour centraliser la gestion des compétences, des projets et des utilisateurs dans un environnement technique complexe.

Développée sur 12 mois, ASKILLS modernise la gestion des talents au sein d'un leader mondial de l'ingénierie, créant une source de vérité unique pour les compétences techniques avec une interface fluide et réactive pensée pour simplifier le quotidien des équipes.

Architecture Technique

Frontend Moderne
React 18 + TypeScript
Vite (Build Ultra-Rapide)

JWT Authentication

Fonctionnalités Principales

Gestion des Compétences

Création, validation et hiérarchisation des compétences techniques avec workflow à deux niveaux

Profils Utilisateurs

Profils enrichis avec auto-évaluation et validation par les pairs

Gestion de Projets

Matching automatique compétences/projets et affectation optimisée

Tableaux de Bord

Analytics et reporting en temps réel sur les compétences disponibles

Défis Techniques Relevés

Synchronisation Temps Réel

Implémentation d'un système de refresh automatique avec Context API

Sécurité Multi-niveaux

RBAC avec 3 niveaux de permissions (Admin, Manager, Collaborateur)

Performance Optimisée

Code splitting avec Vite et lazy loading des routes React

Déploiement Containerisé

Architecture Docker avec Caddy reverse proxy

Stack Technologique

React 18 TypeScript Vite Node.js Express PostgreSQL Prisma ORM Docker JWT Caddy Bootstrap 5
