Transformation digitale pour Assystem

Application moderne conçue pour centraliser la gestion des compétences, des projets et des utilisateurs dans un environnement technique complexe.

Développée sur 12 mois, Askills modernise la gestion des talents au sein d'un leader mondial de l'ingénierie en créant une source de vérité unique pour les compétences techniques. Avec une interface fluide et réactive pensée pour simplifier le quotidien des équipes, elle s'appuie sur une stack React 18 / TypeScript côté client et un backend Node.js + Express exposant une API REST sécurisée par JWT, le tout orchestré via Docker.

Fonctionnalités

Fonctionnalités principales

Gestion des compétences

Création, validation et hiérarchisation des compétences techniques avec un workflow à deux niveaux (Manager → Admin).

Profils utilisateurs

Profils enrichis avec auto-évaluation et validation par les pairs, offrant une vue complète des expertises de chaque collaborateur.

Gestion de projets

Matching automatique compétences/projets et affectation optimisée des ressources humaines selon les besoins opérationnels.

Tableaux de bord

Analytics et reporting en temps réel sur les compétences disponibles pour piloter les décisions RH et opérationnelles.

Sécurité multi-niveaux

RBAC avec 3 niveaux de permissions distincts (Admin, Manager, Collaborateur) garantissant une séparation stricte des droits.

Temps réel

Rafraîchissement automatique des données via hooks React personnalisés et Context API, sans rechargement de page.

Ingénierie

Défis techniques relevés

01

Synchronisation temps réel

Système de rafraîchissement automatique via des hooks React personnalisés et le Context API — garantissant la cohérence des données entre tous les composants sans rechargement de page.

02

Sécurité & contrôle d'accès

Système RBAC à 3 niveaux (Admin, Manager, Collaborateur) avec validation JWT côté serveur et protection des routes côté client, assurant une séparation stricte des droits.

03

Performance optimisée

Code splitting automatique avec Vite et lazy loading des routes React, réduisant le bundle initial et maintenant des temps de réponse API inférieurs à 200 ms même sous charge.

04

Déploiement containerisé

Architecture Docker multi-conteneurs (frontend, backend, base de données) derrière un reverse proxy Caddy, pour des mises en production reproductibles et un HTTPS automatique.
